# 🚀 AI Multi-Agent HR Analytics Platform

A full-stack AI-powered HR Analytics platform built using:

- React + Vite
- FastAPI
- Ollama (Local LLM for development)
- Multi-Agent Architecture
- WebSockets
- Multiple LLM Provider Support (Upcoming)

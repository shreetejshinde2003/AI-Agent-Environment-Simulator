# Company Multi-Agent Datasets

## Project Description

This project contains company-oriented datasets designed for a Multi-Agent System (MAS). The datasets are organized into Small, Medium, and Large versions for testing and development.

## Folder Structure

```
Company-MultiAgent-Datasets/
│
├── small/
├── medium/
├── large/
└── architecture/
```

## Datasets

### Employees Dataset
Contains employee details such as:
- Employee ID
- Department
- Job Role
- Salary
- Performance Rating

### HR Dataset
Contains HR-related information:
- Employee Name
- Department
- Manager ID
- Job Role
- Employment Status

### Performance Dataset
Contains:
- Employee Performance
- Productivity
- Projects
- Salary
- Department

## Multi-Agent System

The system includes the following agents:

- CEO Agent
- HR Agent
- Engineering Agent
- Finance Agent
- Performance Agent

These agents communicate through shared company datasets to automate company operations.
